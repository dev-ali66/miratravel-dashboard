# CMS Master Change Flow

## Purpose
Use this as the single ordered flow for CMS changes.

## Rule
- Do one small change at a time.
- Check the result.
- Then move to the next step.
- Do not try to change everything in one pass.

## How to use this
When the user says to continue, follow the next unchecked step in the relevant flow.
If the change is section-specific, work only on that section.
If the change is shared, update the shared doc or shared component first.

## Result
This keeps CMS work consistent, small, and easy to check.
